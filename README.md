# Tech Tayari

A free, offline-first course in computers, the internet, AI and Computer Studies for Kenyan learners in Grade 4–11, aligned to CBE and the KICD curriculum designs.

**Try it:** https://techtayari.co.ke. It works on any phone browser, needs no login, and keeps working offline once loaded.

| Track | Grades | Modules |
|---|---|---|
| Digital Foundations | 4–6 | D1–D5 |
| Computers & Networks | 7–9 | C1–C10 |
| AI Basics | 7–11 | A1–A6 |
| Computer Studies I | 10 | S1–S12 |
| Computer Studies II | 11 | S13–S23 |

Every module runs through the same steps: **Read → Listen → Watch → Mission → Quiz**, with hands-on tasks, animated explainers and mastery levels.

## Help improve the lessons

The lessons are Markdown files in [`content/`](content/). To fix something, open a file on GitHub, click ✏️ and propose the change. No programming is needed. The format is explained in [content/README.md](content/README.md).
