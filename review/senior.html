S1 · How Computers Evolved

History and architecture · CBE strand · Grade 10 · 1.1 Evolution of Computers · 1.2 Computer Architecture · lesson page

Reading cards

🧮 Calculating before electricity Card 1

People built calculating tools long before electricity: the abacus, Napier's bones, the slide rule and Blaise Pascal's adding machine, the Pascaline (1642). In the 1830s Charles Babbage designed the Analytical Engine, a programmable machine, and Ada Lovelace wrote what is often called the first computer program for it.

⚡ Generations of computers Card 2

Electronic computers are often grouped into generations by the technology inside: first, vacuum tubes (1940s–50s); second, transistors; third, integrated circuits (many transistors on one chip); fourth, microprocessors, a whole CPU on one chip (from the 1970s). Some books call today's AI-focused systems the fifth generation.

📉 Smaller, faster, cheaper Card 3

Each generation made computers smaller, faster, cheaper and less power-hungry. ENIAC (1945) filled a large room and weighed about 27 tonnes. A modern smartphone is millions of times more powerful and fits in your pocket.

🏛️ The von Neumann architecture Card 4

Most computers follow the von Neumann architecture: a CPU, a memory that holds both the program and the data, input and output devices, and buses connecting them. The CPU repeats one cycle: fetch an instruction from memory, decode it, execute it.

🔌 Buses: the computer's roads Card 5

A bus is a set of wires carrying signals between parts. The data bus carries the data itself, the address bus carries the memory location to read or write, and the control bus carries commands such as read, write and clock signals.

Narration

  • Before electricity, people calculated with the abacus, the slide rule and Pascal's adding machine.
  • Babbage designed a programmable engine, and Ada Lovelace wrote a program for it.
  • Computer generations moved from vacuum tubes to transistors, chips, and microprocessors.
  • Every step made computers smaller, faster and cheaper.
  • Most computers keep programs and data in the same memory: the von Neumann design.
  • The CPU fetches, decodes and executes instructions, over and over.
  • Buses carry data, addresses and control signals between the parts.

S2 · Input & Output

Devices and how to choose them · CBE strand · Grade 10 · 1.3 Input/Output (I/O) Devices · lesson page

Reading cards

⌨️ Input devices Card 1

Input devices turn things in the real world into data the computer can process. Keyboards and mice are the familiar ones. Others include touch screens, microphones, cameras and scanners, and sensors that measure temperature, light or movement.

🔎 Automatic data capture Card 2

Some input devices read data without anyone typing. A barcode or QR code reader at the supermarket, Optical Mark Recognition (OMR) for multiple-choice answer sheets, Magnetic Ink Character Recognition (MICR) for the numbers on bank cheques, and fingerprint readers (biometrics) for identity.

🖨️ Output devices Card 3

Output devices present processed data to people. A monitor or projector gives soft copy, which you can see but not hold. A printer gives hard copy on paper; inkjets spray tiny ink drops, laser printers fuse toner with heat. Speakers and headphones give sound output.

🔁 Both input and output Card 4

Some devices do both jobs. A touch screen shows information and accepts taps. A headset has speakers and a microphone. A storage drive receives data and gives it back later.

🔌 Connecting devices Card 5

Devices connect through ports and wireless links: USB for most accessories, HDMI for screens and projectors, audio jacks, and wireless such as Bluetooth and Wi-Fi. Pick devices by the job: speed, accuracy, cost, the volume of data, and the needs of the user, for example screen readers for blind users.

Narration

  • Input devices turn the real world into data: keyboards, mice, cameras, sensors.
  • Some devices capture data automatically, like barcode readers and OMR answer sheets.
  • MICR reads the special magnetic numbers on bank cheques.
  • Monitors give soft copy; printers give hard copy on paper.
  • Touch screens and headsets are both input and output.
  • USB, HDMI and Bluetooth connect devices to the computer.
  • Choose a device for the job: speed, accuracy, cost and who will use it.

S3 · Storage & the CPU

Memory, storage and the processor · CBE strand · Grade 10 · 1.4 Computer storage · 1.5 Central Processing Unit (CPU) · lesson page

Reading cards

🧠 Primary storage Card 1

Primary storage is memory the CPU uses directly. RAM holds the programs and data in use right now and is volatile: it is wiped when power goes off. ROM is non-volatile and holds start-up instructions (firmware). Cache is a small, very fast memory close to the CPU for data it needs again and again.

💾 Secondary storage Card 2

Secondary storage keeps files when the power is off: hard disk drives (HDD) with spinning platters, solid-state drives (SSD) with no moving parts, USB flash drives and memory cards, optical discs (CD, DVD), and cloud storage on someone else's servers over the internet.

📏 Measuring storage Card 3

1 byte is 8 bits. Storage sizes go kilobyte (KB), megabyte (MB), gigabyte (GB), terabyte (TB). In computing, each step is traditionally 1024 times the last (1 KB = 1024 bytes), though drive makers often use 1000. A photo might be 3 MB; a phone might store 128 GB.

🛡️ Caring for storage Card 4

Back up important files in at least two places. Eject flash drives before pulling them out. Keep hard disks away from knocks, heat and strong magnets. Scan removable drives for malware, because they spread infections between computers.

⚙️ Inside the CPU Card 5

The CPU has a Control Unit that directs the fetch–decode–execute cycle, an Arithmetic Logic Unit (ALU) that does calculations and comparisons, and registers: tiny, ultra-fast storage inside the CPU. Speed depends on clock speed (in GHz), the number of cores working in parallel, and cache size.

Narration

  • Primary storage is used directly by the CPU: RAM, ROM and cache.
  • RAM is volatile and forgets everything when the power goes off.
  • ROM keeps its start-up instructions even without power.
  • Secondary storage, like SSDs, hard disks and flash drives, keeps files long-term.
  • One byte is eight bits; then kilobytes, megabytes, gigabytes and terabytes.
  • Back up important files, and always eject flash drives safely.
  • Inside the CPU, the control unit directs, the ALU calculates, and registers hold data.

S4 · Operating Systems

The software that runs everything · CBE strand · Grade 10 · 1.6 Operating System (OS) · lesson page

Reading cards

🧩 What an operating system is Card 1

The operating system (OS) is the main software that manages the computer's hardware and runs other programs. Without it, apps could not use the screen, memory or storage. Examples: Windows, macOS and Linux on computers; Android and iOS on phones.

🗂️ What the OS manages Card 2

The OS manages processes (which programs run, and when), memory (which program uses which part of RAM), files and folders on storage, input and output devices through drivers, and security, such as user accounts and permissions.

🖱️ How you talk to it Card 3

The user interface is how you give the OS instructions. A graphical user interface (GUI) uses windows, icons, menus and a pointer. A command-line interface (CLI) uses typed commands. A GUI is easier to learn; a CLI can be faster for experts and for automation.

🗃️ Types of operating systems Card 4

Single-user systems serve one person at a time; multi-user systems, like servers, serve many at once. Multitasking runs several programs at the same time. Real-time operating systems respond within strict time limits, for example in car brakes or medical machines.

🔐 Keeping the OS healthy Card 5

Install updates: they fix security holes. Use only trusted app stores and sources. Give each person their own user account, and don't use the administrator account for everyday work. Licensed or open-source software is legal; pirated copies often hide malware.

Narration

  • The operating system manages the hardware and runs every other program.
  • Windows, macOS and Linux run computers; Android and iOS run phones.
  • The OS manages processes, memory, files, devices and security.
  • A GUI uses windows and icons; a command line uses typed commands.
  • Multitasking runs several programs; real-time systems respond instantly.
  • Install updates; they close security holes.
  • Get software from trusted sources: pirated copies often hide malware.

S5 · Setting Up a Computer

Ports, cables and safety · CBE strand · Grade 10 · 1.7 Computer setup · lesson page

Reading cards

🔌 Ports and cables Card 1

Each cable fits a matching port. USB (type A is the flat rectangle, type C is small and reversible) connects most accessories. HDMI and DisplayPort carry video and sound to screens; older screens use the blue VGA port. An RJ-45 port takes an Ethernet network cable. The round 3.5 mm jack is for audio.

🔋 Power Card 2

Desktops and monitors usually take a detachable power cable; laptops use a charger. Kenya has power cuts and surges, so plug into a surge protector, or better, a UPS (uninterruptible power supply), whose battery gives you time to save and shut down properly.

🛠️ The setup procedure Card 3

Place the computer on a stable desk with space around it for air. With everything switched off, connect the monitor, then the keyboard and mouse, then the network cable. Connect power last, switch on the monitor, then the computer. Finally, test it by doing a real task.

⚠️ Safety first Card 4

Never open a computer while it is plugged in. Keep drinks away and cables tidy so nobody trips. Use properly earthed sockets and don't overload them. Before touching parts inside, touch bare metal to discharge static electricity, which can damage chips.

♻️ E-waste Card 5

Old computers contain useful parts and also harmful materials like lead. Reuse parts that still work, such as a good monitor or keyboard, to set up another computer. Take broken equipment to licensed e-waste collectors; never burn it or dump it with ordinary rubbish.

Narration

  • Every cable has a matching port: USB, HDMI, VGA, Ethernet and audio.
  • USB type C is small and reversible; type A is the flat rectangle.
  • A UPS keeps the computer running during a power cut so you can save your work.
  • Connect everything with the power off, and connect power last.
  • Never open a computer while it is plugged in.
  • Touch bare metal first to discharge static before handling parts.
  • Reuse working parts, and take broken ones to licensed e-waste collectors.

S6 · Data Communication

How data travels · CBE strand · Grade 10 · 2.1 Data communication · 2.2 Data Transmission Media · lesson page

Reading cards

📨 The five parts of communication Card 1

Every data communication has five parts: a sender, a receiver, the message (the data), a transmission medium that carries it (cable or radio waves), and a protocol: the agreed rules both sides follow so they understand each other. An M-Pesa message from one phone to another uses all five.

↔️ Direction: simplex, half-duplex, full-duplex Card 2

Simplex sends one way only, like a radio broadcast. Half-duplex sends both ways but one at a time, like a walkie-talkie ("over!"). Full-duplex sends both ways at once, like a phone call.

📜 Protocols and layered models Card 3

Protocols are rules for formatting, addressing and checking data. The internet uses the TCP/IP suite: IP addresses and routes packets; TCP makes sure they all arrive in order. The OSI model describes networking in seven layers, from the physical cable up to the application you use.

🧵 Guided media: cables Card 4

Guided media send signals along a physical path. Twisted-pair copper cable (as in Ethernet) is cheap and common. Coaxial cable is used for TV and some internet connections. Fibre-optic cable carries light, so it is very fast, crosses long distances and is not disturbed by electrical interference. It links Kenya to the world under the sea.

📡 Unguided media and bandwidth Card 5

Unguided (wireless) media use radio waves, microwaves, infrared or satellite links: Wi-Fi, Bluetooth and mobile data. Bandwidth is how much data a link can carry per second (for example 100 Mbps). A modem modulates digital data into a signal for the medium and demodulates it back at the other end.

Narration

  • Communication needs a sender, a receiver, a message, a medium and a protocol.
  • Simplex is one way, half-duplex takes turns, and full-duplex goes both ways at once.
  • Protocols are the agreed rules; the internet uses TCP/IP.
  • Twisted pair is cheap, coaxial carries TV, and fibre carries light very fast.
  • Wireless media include Wi-Fi, Bluetooth, mobile data and satellite.
  • Bandwidth is how much data a link carries per second.
  • A modem modulates and demodulates signals between devices.

S7 · Building Networks

Network elements and topologies · CBE strand · Grade 10 · 2.3 Computer Network Elements · 2.4 Network Topologies · lesson page

Reading cards

🗺️ Types of networks by size Card 1

A PAN (personal area network) links devices around one person, like a phone and earbuds over Bluetooth. A LAN (local area network) covers a home, office or school. A MAN (metropolitan area network) covers a city. A WAN (wide area network) spans countries; the internet is the biggest WAN.

🧰 Network devices Card 2

A network interface card (NIC) connects a device to a network. A switch joins devices in a LAN and sends data only to the right one. A router connects different networks, such as your LAN to the internet, and picks routes for packets. A wireless access point lets devices join by Wi-Fi. A modem connects to the service provider's line.

✅ Choosing a network Card 3

When planning a network, consider: cost, the number of users, distance, the speed needed, security, and how easy it is to grow and maintain. A school lab of 30 computers needs different equipment from one family's home.

🕸️ Physical and logical topology Card 4

Topology is the layout of a network. Physical topology is how devices are actually cabled; logical topology is how data flows between them. They can differ: a network can be wired as a star but pass data as if in a ring.

⭐ Common physical topologies Card 5

Bus: all devices share one main cable; cheap, but one break stops everything. Star: each device connects to a central switch; easy to fix, but the switch is a single point of failure. Ring: devices form a loop. Mesh: devices have many links, so data can go around failures. Tree: stars connected in levels, common in schools.

Narration

  • Networks by size: PAN, LAN, MAN, and WAN, the biggest of which is the internet.
  • A switch joins devices in a LAN; a router connects networks together.
  • A NIC connects a device; an access point adds Wi-Fi.
  • Plan a network by cost, users, distance, speed and security.
  • Physical topology is the cabling; logical topology is how data flows.
  • In a bus, one break stops all; in a star, the centre is critical.
  • Mesh networks route around failures, which makes them reliable.

S8 · Thinking Like a Programmer

Programming concepts and program development · CBE strand · Grade 10 · 3.1 Computer Programming Concepts · 3.2 Program development · lesson page

Reading cards

🗣️ Programming words Card 1

A program is a set of instructions for a computer. Source code is the program as a person writes it. Syntax is the grammar rules of a language. A bug is a mistake; debugging is finding and fixing it. An IDE (integrated development environment) is an app for writing, running and debugging code.

🪜 Levels of programming languages Card 2

Machine code is pure binary that the CPU runs directly. Assembly language uses short words (mnemonics) like ADD and MOV, one per machine instruction. High-level languages such as Python, Java, C++ and Scratch read more like English and work on many computers. These lessons use Python.

⚙️ Compilers and interpreters Card 3

The CPU only understands machine code, so high-level code must be translated. A compiler translates the whole program first, producing a file that runs fast. An interpreter translates and runs it one line at a time, which makes testing easy. Python usually runs through an interpreter.

🔄 Stages of program development Card 4

Programs are built in stages: define the problem, design a solution (the algorithm), write the code, test and debug it, put it into use, then document and maintain it. Skipping design and testing is how bugs reach users.

🧭 Algorithms, pseudocode and flowcharts Card 5

An algorithm is a step-by-step solution. A good one is clear, finite (it ends), has inputs and outputs, and every step can actually be done. Pseudocode writes it in plain structured English (START, INPUT, OUTPUT, END). Flowcharts draw it: ovals for start and end, parallelograms for input and output, rectangles for processing, diamonds for decisions.

Narration

  • Source code is what programmers write; syntax is the language's grammar.
  • A bug is a mistake, and debugging is fixing it.
  • Machine code is binary; assembly uses short words; high-level languages read like English.
  • A compiler translates everything first; an interpreter runs line by line.
  • Programs are built in stages: define, design, code, test, use, maintain.
  • A good algorithm is clear, finite and has inputs and outputs.
  • In flowcharts, diamonds are decisions and parallelograms are input and output.

S9 · Variables & Operators

Identifiers, data types and operators in Python · CBE strand · Grade 10 · 3.3 Identifiers and Operators · lesson page

Reading cards

📦 Variables and constants Card 1

A variable is a named box in memory whose value can change, for example marks = 85. A constant is a value that should not change while the program runs. Python has no special constant type, so by convention constants are written in capitals: PASS_MARK = 50.

🏷️ Naming rules (identifiers) Card 2

An identifier is the name you give a variable or function. In Python it may contain letters, digits and underscores, but must not start with a digit, must have no spaces, and must not be a keyword like if, for or class. Names are case-sensitive: Marks and marks are different. Choose meaningful names like total_fees, not x.

🔤 Data types Card 3

Every value has a type. int is a whole number (42), float is a decimal (3.5), str is text in quotes ("Nairobi"), and bool is True or False. The type decides what you can do: 5 + 3 is 8, but "5" + "3" joins text and gives "53".

⌨️ Input and output Card 4

print() shows output on the screen. input() reads what the user types, and always gives back text (a str). To do maths with it, convert it first: age = int(input("Age? ")).

➕ Operators Card 5

Arithmetic: + − * / for add, subtract, multiply and divide, // for whole-number division, % for the remainder, ** for power. Comparison: == (equal to), != (not equal), <, >, <=, >=, which give True or False. Logical: and, or, not combine conditions. = assigns a value; == compares.

Narration

  • A variable is a named box whose value can change.
  • By convention, constants are written in capitals, like PASS_MARK.
  • Names can't start with a digit, can't have spaces, and can't be keywords.
  • int is whole numbers, float is decimals, str is text, bool is True or False.
  • input always gives text, so convert it with int before doing maths.
  • Double slash divides to a whole number; percent gives the remainder.
  • One equals sign assigns; two equals signs compare.

S10 · Decisions & Loops

Control structures in Python · CBE strand · Grade 10 · 3.4 Control Structures · lesson page

Reading cards

🛤️ Three control structures Card 1

Every program is built from three structures. Sequence: steps run one after another. Selection: the program chooses a path with if. Iteration: the program repeats steps with a loop. Combine these and you can solve almost any problem.

🔀 Selection with if, elif and else Card 2

if checks a condition; elif ("else if") checks another; else runs when none matched. For example: if marks >= 80, print "A"; elif marks >= 50, print "Pass"; else print "Try again". Python uses a colon and indentation (usually 4 spaces) to show which lines belong to each branch.

🔁 for loops Card 3

A for loop repeats once for each item. range(5) gives 0, 1, 2, 3, 4 (five numbers, starting at 0). range(1, 6) gives 1 to 5. Example: for i in range(3): print(i) prints 0, then 1, then 2.

⏳ while loops Card 4

A while loop repeats as long as a condition is True, which suits cases where you don't know how many repeats are needed, like asking for a PIN until it is correct. Make sure something inside the loop changes the condition, or it will loop forever.

⛔ break and continue Card 5

break leaves a loop immediately, for example when you find what you were searching for. continue skips the rest of this round and jumps to the next one, for example to skip negative numbers. Use them sparingly, to keep loops easy to follow.

Narration

  • Programs use three structures: sequence, selection and iteration.
  • if, elif and else choose which path the program takes.
  • Python uses a colon and indentation to show what belongs to each part.
  • A for loop repeats once for each item, and range starts counting at zero.
  • A while loop repeats as long as a condition stays true.
  • Make sure a while loop's condition eventually becomes false.
  • break leaves a loop; continue skips to the next round.

S11 · Lists & Searching

Data structures, sorting and searching · CBE strand · Grade 10 · 3.5 Data Structures · lesson page

Reading cards

📋 Lists Card 1

A list holds many values in order, in square brackets: marks = [70, 85, 90]. Positions (indexes) start at 0, so marks[0] is 70 and marks[2] is 90. Lists can change: marks.append(65) adds a value at the end, and len(marks) tells you how many items there are.

🔒 Tuples and sets Card 2

A tuple is like a list but cannot be changed once made, in round brackets: point = (3, 4). Use one for data that should stay fixed. A set holds unique values in curly brackets: {"Maths", "English"}. Adding a duplicate does nothing, which makes sets great for removing repeats.

📒 Dictionaries Card 3

A dictionary stores key and value pairs, like a phone book: phones = {"Amani": "0712 000 000"}. You look values up by key, phones["Amani"], instead of by position. Keys must be unique.

🗄️ Two-dimensional lists Card 4

A list can hold other lists, like a table with rows and columns: table = [[1, 2], [3, 4]]. table[1][0] means row 1, column 0, which is 3. This is useful for timetables, spreadsheets and game boards.

🔍 Searching and sorting Card 5

Linear search checks items one by one from the start; it works on any list but is slow for big ones. Binary search needs a sorted list: check the middle, then throw away the half that can't contain the target, and repeat, which is very fast. Bubble sort sorts by repeatedly swapping neighbours that are in the wrong order.

  • A set keeps only unique values.
  • A dictionary stores key and value pairs, like a phone book.
  • Linear search checks every item; binary search halves a sorted list each time.

S12 · Functions

Modular programming · CBE strand · Grade 10 · 3.6 Functions · lesson page

Reading cards

🧱 Why functions? Card 1

A function is a named block of code that does one job. Modular programming breaks a big program into functions, so each part is easier to write, test, fix and reuse. It is like a school: each department does its own job, and together they run everything.

🧰 Built-in and user-defined Card 2

Built-in functions come with Python: print(), input(), len(), int(), max(), round(). User-defined functions are the ones you write yourself with def. Once defined, you can call your function as many times as you like.

✍️ Defining a function Card 3

def area(length, width): return length * width. This defines a function named area with two parameters. Calling area(3, 4) passes 3 and 4 in as arguments, and the function returns 12. Inside a real program, the body goes on its own indented lines under the def line.

↩️ Parameters and return values Card 4

Parameters are the names in the definition (length, width); arguments are the actual values you pass in (3, 4). return sends a result back to the caller and ends the function. A function without return gives back the special value None.

🔭 Scope: local and global Card 5

A variable created inside a function is local: it exists only while the function runs and can't be used outside it. A variable created outside all functions is global. Prefer passing values in as parameters and returning results; it keeps functions independent and easy to test.

Narration

  • A function is a named block of code that does one job.
  • Modular programs are easier to write, test, fix and reuse.
  • Python has built-in functions like print and len, and you can write your own with def.
  • Parameters are names in the definition; arguments are the values you pass in.
  • return sends a result back and ends the function.
  • Variables made inside a function are local to it.
  • Pass values in and return results, so functions stay independent.
