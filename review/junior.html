C1 · Boot Up

The Motherboard · CBE strand · Grade 7–9 · Hardware basics: the motherboard & boot · lesson page

Reading cards

🔘 Press power Card 1

When you press power, a small program on the motherboard called the BIOS/UEFI wakes first. It does a roll call: CPU? RAM? Storage? All present? Then it hands over to the operating system (Windows, Linux or macOS).

🟩 The motherboard Card 2

Every part plugs into the motherboard. Its printed lines (traces) are like roads carrying signals between parts very fast. The graphics card sits in the longest slot because it moves the most data.

🗣️ Drivers are translators Card 3

The operating system doesn't automatically know how to talk to each part. A driver is a small translator program (from the part's maker) that lets the OS and the device understand each other. Updating drivers can fix bugs and improve performance.

🚀 Opening a program Card 4

When you open an app, its files move from storage (the disk) into RAM. The CPU then runs the instructions and the GPU draws what you see. The whole team starts working together.

Narration

  • Let's follow what happens when a computer starts.
  • You press power. The BIOS or UEFI wakes and does a roll call of the parts.
  • Then it hands over to the operating system.
  • Every part plugs into the motherboard, which carries signals between them.
  • A driver is a translator that lets the OS talk to each device.
  • Open an app and its files move from storage into RAM.
  • The CPU runs the instructions and the GPU draws the screen. Tayari!

Mission: Read your computer's spec

  • On Windows press the Windows key, type 'System information' and open it (or on a phone open Settings > About).
  • Write down the Processor (CPU) and the installed RAM.
  • Find the storage size and how much is free.

C2 · The CPU

The Processor · Going further · lesson page

Reading cards

🧠 The decision maker Card 1

The CPU runs the instructions of every program: working out sums, moving data, deciding what happens next. In a game it tracks players and rules; in a browser it builds the page.

⏱️ Clock speed (GHz) Card 2

A CPU works to a beat called the clock. 3 GHz means about 3 billion beats per second, and on each beat it does a little work. More GHz can mean more work per second — but it's not the only thing that matters.

💪 Newer can be smarter Card 3

A newer CPU can beat an older one at the same GHz because it does more useful work on each beat (better design). Speed numbers alone don't tell the whole story.

👥 Cores and threads Card 4

A core is a worker inside the CPU. Many CPUs have several cores, so they can do several jobs at once. Some apps use many cores; others lean on one fast core.

🗄️ Cache: the near shelf Card 5

Cache is a small, very fast memory on the CPU itself. Grabbing data from cache is quicker than going to RAM, like keeping your most-used book on the desk instead of the shelf.

Narration

  • The CPU runs the instructions of every program.
  • It works to a beat called the clock, measured in GHz.
  • 3 GHz is about 3 billion beats a second, doing a little work each beat.
  • A newer CPU can beat an older one at the same speed — better design.
  • A core is a worker inside the CPU; many cores do several jobs at once.
  • Cache is tiny, very fast memory right on the chip.
  • Grabbing from cache is quicker than going all the way to RAM.

Mission: Watch the CPU work

  • Open Task Manager (Ctrl+Shift+Esc on Windows) or a system monitor, and open the CPU graph.
  • Write down how many cores / logical processors it shows.
  • Open a few programs and watch the CPU usage rise. Which activity used it most?

  • 3 thousand beats per second

Giga means billion, so 3 GHz is about 3,000,000,000 clock beats every second, with a little work done on each beat.

  • ✓ A worker inside the CPU that runs instructions
  • A small store of memory beside the CPU
  • The cooling fan fitted on top of the CPU

Each core can run its own stream of instructions, so a CPU with more cores can work on more jobs at the same time.

Q5. Cache is...

  • ✓ Small, very fast memory on the CPU
  • Large, slow storage on the hard disk
  • The extra RAM sticks you can add later

Cache sits right next to the cores, so data in it can be reached much faster than data in RAM, saving waiting time.

  • ✓ It does more useful work per beat

Newer designs complete more instructions on each clock beat, so they finish the same work sooner even at the same GHz.

Q7. Getting data from cache instead of RAM is...

  • ✓ Faster
  • Slower

  • Only possible when offline

Cache is on the CPU chip itself, close to the cores, so it answers much more quickly than RAM out on the motherboard.

  • ✓ Independent processing units on one chip
  • Power supplies built into one case
  • Screens connected to one graphics card
  • Storage drives joined together as one big drive

Each core is a complete processing unit, so a multi-core chip can run several streams of instructions in parallel instead of one after another.

Q9. Why is CPU cache divided into levels like L1, L2, and L3?

  • ✓ L1 is smallest and fastest; L3 is larger but slower
  • L1, L2 and L3 are all the same size and speed
  • L1 stores the OS; L3 stores your saved files
  • L3 is the fastest because it holds the most data

Very fast memory is costly and takes up space, so the CPU uses a tiny, quick L1 backed by larger, slightly slower L2 and L3.

Q10. What does IPC stand for in processor performance?

  • ✓ Instructions Per Clock
  • Internet Protocol Connection
  • Input Processing Cache
  • Internal Power Control

IPC counts how many instructions a CPU completes on each clock beat; higher IPC means more work done at the same GHz.

C3 · The GPU

The Graphics Chip · Going further · lesson page

Reading cards

🔺 Built from triangles Card 1

Everything in a 3D game or 3D map is built from many small triangles. The GPU's job is to place all those triangles and colour them, extremely fast.

🎨 Painting pixels Card 2

Your screen is made of tiny dots called pixels. A Full HD screen has about 2 million; a 4K screen has about four times as many — that's why 4K is heavier work.

🐜 Many small workers Card 3

A GPU has thousands of tiny cores that each colour a few pixels at the same time. Doing many small jobs in parallel is what makes graphics fast.

💡 Shading and light Card 4

Small programs called shaders add light, shadow and shine. Some GPUs do ray tracing — following how light really bounces — for realistic reflections, but it is heavy work.

🔍 Upscaling tricks Card 5

Techniques like DLSS/FSR render a smaller image then cleverly enlarge it, giving more frames per second for less work. Beyond games, GPUs also speed up video editing and AI.

Narration

  • The GPU draws what you see on the screen.
  • 3D scenes are built from many small triangles.
  • The screen is made of pixels; 4K has about four times as many as Full HD.
  • A GPU has thousands of tiny cores colouring pixels at the same time.
  • Doing many small jobs at once is what makes graphics fast.
  • Shaders add light and shadow; ray tracing follows real light — heavy work.
  • GPUs also speed up video editing and AI, not just games.

Mission: Resolution test

  • If you can, play a video or game and note how smooth it feels.
  • Lower the resolution one step and see if it feels smoother. Put it back after.

C4 · RAM & Storage

Memory and the Disk · CBE strand · Grade 7–9 · Memory & storage basics · lesson page

Reading cards

🎒 RAM is the backpack Card 1

RAM holds what the computer is using right now: the open app, the page you're reading. It is very fast but it empties when you switch off.

📚 Storage is the shelf Card 2

Storage (the disk) keeps everything even with the power off: your apps, documents, photos, music. SSDs are fast; older hard disks (HDD) spin a platter and are slower.

🚀 SSD vs HDD Card 3

An SSD has no moving parts and loads much faster than a spinning hard disk. The fastest type, NVMe, makes programs and files open quickly.

🐌 When RAM fills up Card 4

If RAM fills, the computer borrows slower space on the disk and everything feels sluggish. Closing unused browser tabs and apps frees the backpack.

📏 How big? Card 5

RAM is usually a few GB (e.g. 4, 8, 16). Storage is bigger — often hundreds of GB or 1 TB. More RAM helps with many apps open; more storage holds more files.

Narration

  • RAM holds what the computer is using right now — and empties when off.
  • Storage, the disk, keeps everything even with the power off.
  • An SSD has no moving parts and is much faster than an old hard disk.
  • NVMe SSDs are the fastest and open programs quickly.
  • If RAM fills up, the computer slows down.
  • Close unused tabs and apps to free the backpack.
  • RAM is a few GB; storage is often hundreds of GB or a whole terabyte.

Mission: Memory detective

  • In Task Manager > Performance (or a monitor), note total RAM and how much is in use.
  • Open about ten browser tabs and check RAM again. Did it rise?
  • Find whether your disk is an SSD or HDD, and its size.

  • It has a spinning metal disk that turns very fast
  • It keeps all data in RAM while the PC is on
  • It is physically bigger than a hard disk

A hard disk must spin its platter and move a reading arm to find data; flash chips are read electronically with no waiting.

C5 · Speed & Lag

Smooth vs Slow · Going further · lesson page

Reading cards

📓 Frames per second Card 1

Video and games are many still pictures shown quickly — like a flip-book. FPS means frames per second. More frames look smoother; 30 is okay, 60 is smooth.

⚡ Two kinds of slow Card 2

There are two different problems. Low FPS means the computer is struggling to draw fast enough. High ping/latency means the connection to a far-away server is slow. A faster computer cannot fix slow internet, and vice versa.

📡 Ping and latency Card 3

Ping (latency) is how long a message takes to reach a server and come back, measured in milliseconds (ms). Low ping feels instant; high ping makes online things feel delayed.

🖥️ Screen refresh (Hz) Card 4

A screen refreshes a set number of times each second, measured in Hz. A 60 Hz screen can show up to 60 frames a second. More frames than the screen can show won't look smoother on it.

⚖️ Find the bottleneck Card 5

When something is slow, ask: is the computer busy (high CPU/GPU use = upgrade or lower settings) or is the internet slow (high ping = a network problem)? Naming the real cause saves time.

Narration

  • Video and games are many pictures shown quickly, like a flip-book.
  • FPS means frames per second — more frames look smoother.
  • There are two kinds of slow: low FPS, and high ping.
  • Low FPS means the computer is struggling to draw fast enough.
  • High ping means the connection to a far server is slow.
  • A fast computer can't fix slow internet, and the other way round.
  • When something lags, ask which one it is. That's how experts fix it.

Mission: Lag detective

  • Open Command Prompt/Terminal and type: ping google.com — note the time in ms.
  • Try an online video; does it buffer (internet) or stutter while the device is busy (computer)?
  • Decide: was a recent slow moment an FPS problem or a ping problem?

Frames are drawn by your own hardware, so a faster internet plan cannot raise FPS; a better GPU or lower settings can.

C6 · Stay Safe & Smart Online

Security · CBE strand · Grade 7–9 · Digital safety & security · lesson page

Reading cards

🔒 Strong, unique passwords Card 1

Use a long password and a different one for each important account. A passphrase like 'twoGoats!eatGrass' is strong and easier to remember than 'p@ss'. Never reuse your email password elsewhere.

🔑 Two-step verification Card 2

Turn on 2FA (two-step verification) where you can: a password PLUS a code (SMS or an app). Even if someone learns your password, they still can't get in. Like two locks on one door.

🎣 Phishing and scams Card 3

Phishing is a fake message pretending to be a bank, M-Pesa or a friend, trying to steal your login or money. Clues: urgency ('act NOW'), odd links, spelling mistakes, requests for a PIN or password. Confirm before you click.

👤 Your digital footprint Card 4

What you post can last forever and be copied, even from a 'private' chat. Before posting, ask: would I be fine with my parent, teacher and future employer seeing this?

⚖️ Balance and wellbeing Card 5

Apps are designed to keep you scrolling. Decide your own limits, take breaks, protect your sleep, and keep time for people and activities offline. Being in control is a skill worth building.

Narration

  • Use a long, unique password for each important account.
  • A passphrase like two-goats-eat-grass is strong and memorable.
  • Turn on two-step verification — a password plus a code. Two locks.
  • Phishing is a fake message trying to steal your login or money.
  • Clues: urgency, odd links, and asking for your PIN or password.
  • What you post can last forever, so think before you post.
  • Apps want endless scrolling. Set your own limits and protect your sleep.

Mission: Lock down an account

C7 · Power & Cooling

Energy and Heat · Going further · lesson page

Reading cards

⚡ The power supply Card 1

The power supply (PSU) takes mains electricity and converts it to the steady low voltages each part needs. A good, reliable PSU protects the whole computer.

🔌 Watts and demand Card 2

Power is measured in watts. A powerful GPU can draw a lot; the PSU must supply enough for all parts, with some to spare. Phones and laptops use far less than big desktops.

🔥 Work makes heat Card 3

When the CPU and GPU work hard they get hot. If they get too hot they slow themselves down (thermal throttling) to stay safe — so good cooling keeps performance up.

🧊 Thermal paste & coolers Card 4

A thin layer of thermal paste between a chip and its cooler helps heat flow into the metal fins, which fans or liquid then carry away.

🌬️ Airflow and dust Card 5

Cool air should enter the front and hot air leave the back and top (hot air rises). Dust blocks airflow, so keeping vents clean keeps a computer cool — important in dusty conditions.

Narration

  • Power is measured in watts; the PSU must supply enough for all parts.
  • Working hard makes the CPU and GPU hot.
  • Too hot and they slow down to stay safe — that's thermal throttling.
  • Thermal paste helps heat flow from the chip into the cooler.
  • Fans or liquid then carry the heat away.
  • Cool air in the front, hot air out the back. Dust blocks airflow, so clean the vents.

C8 · Bits & Bytes

How Big Is Data · Going further · lesson page

Reading cards

💡 The bit Card 1

Deep down a computer uses switches that are either OFF or ON, written 0 or 1. One such switch is a bit — the smallest piece of information.

📦 8 bits = a byte Card 2

Eight bits grouped together make a byte. One byte can store a single letter, like the 'A' in your name. Your full name is just a few bytes.

🪜 The size ladder Card 3

About 1000 bytes = 1 kilobyte (KB). About 1000 KB = 1 megabyte (MB). About 1000 MB = 1 gigabyte (GB). About 1000 GB = 1 terabyte (TB). Each step is roughly a thousand times bigger.

📱 Everyday sizes Card 4

A text message is a few bytes. A photo is a few MB. A music track is a few MB. A long HD video or a big app is hundreds of MB to several GB. A phone might store 128 GB.

📶 Speed vs size Card 5

Internet speed is measured in megabits per second (Mbps, small b). File size is in megabytes (MB, big B). Since 8 bits = 1 byte, a 16 Mbps link downloads about 2 MB each second — handy to know when buying a data bundle.

Narration

  • Deep down a computer uses switches: off or on, 0 or 1. That's a bit.
  • Eight bits make a byte, which can store one letter.
  • About a thousand bytes is a kilobyte; a thousand KB is a megabyte.
  • A thousand MB is a gigabyte; a thousand GB is a terabyte.
  • A photo is a few MB; a long video is hundreds of MB to several GB.
  • Internet speed is in megabits (small b); files are in megabytes (big B).
  • Eight bits per byte, so a 16 Mbps link does about 2 MB a second. Good for bundles!

Mission: Size and speed

  • Check the size of a photo and a video on your device (in MB or GB).
  • Find your phone's total storage and how much is free.
  • With a grown-up, note your data bundle speed (Mbps) and estimate the MB per second.

C9 · The Network

From Device to Server · CBE strand · Grade 7–9 · Networks: device to server · lesson page

Reading cards

🏠 Your local network (LAN) Card 1

At home or school your devices connect to a router — by Wi-Fi or cable — forming a Local Area Network (LAN). The router is the gateway between your LAN and the wider internet.

📮 Packets Card 2

Data is split into small packets, each labelled with where it's going and where it came from, like addressed envelopes. They travel separately and are reassembled at the destination.

🌍 ISP and the wider internet Card 3

Your router passes packets to your ISP (e.g. Safaricom, Zuku, JTL). The ISP connects to other networks — through cables, fibre, and undersea cables — until your packets reach the right server, maybe on another continent.

🔢 IP addresses Card 4

Every device on a network has an IP address, a number that identifies it, like a postal address. Packets use IP addresses to find their way. Public IPs are reachable on the internet; private IPs (like 192.168.x.x) are used inside your LAN.

⏱️ Why distance matters Card 5

A server far away means packets travel further, so ping is higher. Content delivery networks (CDNs) keep copies of popular content closer to users to make it faster — one reason some sites load quicker than others.

Narration

  • At home your devices connect to a router, forming a local network, a LAN.
  • The router is the gateway between your LAN and the wider internet.
  • Data travels as packets, like addressed envelopes.
  • Your router passes packets to your ISP, like Safaricom or Zuku.
  • The ISP connects to other networks, even by undersea cables.
  • Every device has an IP address, like a postal address, so packets find their way.
  • A far server means higher ping; CDNs keep copies closer to speed things up.

C10 · How the Web Works

Domains, DNS & HTTPS · CBE strand · Grade 7–9 · How the web works: domains, DNS & HTTPS · lesson page

Reading cards

🔗 Websites vs the internet Card 1

The internet is the network of connected computers. The World Wide Web (WWW) is the pages and sites you view with a browser, which ride on top of the internet. The web is one of many things the internet carries.

🏷️ Domain names Card 2

Computers find each other by IP address (numbers), but numbers are hard to remember. A domain name like safaricom.co.ke is a friendly label for a website. Names end in parts like .com, .org, or Kenya's .ke / .co.ke.

📖 DNS: the internet's address book Card 3

DNS (Domain Name System) turns a domain name into its IP address — like a phone contact list turning a name into a number. When you type a site, your device asks a DNS resolver 'what's the IP for this name?' and gets an answer, usually in milliseconds.

📨 Loading a page: request & response Card 4

Your browser sends an HTTP request to the site's server ('please send me this page'). The server replies with an HTTP response containing the page — text, images and code — which the browser puts together and shows you.

🔒 HTTP vs HTTPS Card 5

HTTPS is HTTP with encryption (TLS): the data is scrambled so others on the network can't read or change it. The padlock means the connection is private and the site proved its identity with a certificate. Never enter a password or pay on plain HTTP.

🛡️ Trust and certificates Card 6

A site's certificate is issued by a trusted authority and ties the domain to its owner. It's why the padlock matters — it helps confirm you're really talking to safaricom.co.ke and not an impostor. Phishing sites often use look-alike names, so check the address carefully.

Narration

  • The internet is the network; the web is the pages you view in a browser.
  • Computers find each other by IP address, but numbers are hard to remember.
  • A domain name like safaricom.co.ke is a friendly label for a site.
  • DNS turns that name into its IP address, like a contact list turning a name into a number.
  • Your browser sends a request; the server sends back the page. Request and response.
  • HTTPS adds encryption so others can't read or change your data.
  • The padlock and a certificate help prove you're talking to the real site. Check the address!
