# C8 · Bits & Bytes

## Read

### 💡 The bit

Deep down a computer uses switches that are either OFF or ON, written 0 or 1. One such switch is a bit — the smallest piece of information.

### 📦 8 bits = a byte

Eight bits grouped together make a byte. One byte can store a single letter, like the 'A' in your name. Your full name is just a few bytes.

### 🪜 The size ladder

About 1000 bytes = 1 kilobyte (KB). About 1000 KB = 1 megabyte (MB). About 1000 MB = 1 gigabyte (GB). About 1000 GB = 1 terabyte (TB). Each step is roughly a thousand times bigger.

### 📱 Everyday sizes

A text message is a few bytes. A photo is a few MB. A music track is a few MB. A long HD (high definition) video or a big app is hundreds of MB to several GB. A phone might store 128 GB.

### 📶 Speed vs size

Internet speed is measured in megabits per second (Mbps, small b). File size is in megabytes (MB, big B). Since 8 bits = 1 byte, a 16 Mbps link downloads about 2 MB each second — handy to know when buying a data bundle.

## Quiz

### The smallest piece of information is a...
- [x] Bit
- [ ] Byte
- [ ] Gigabyte
- [ ] Pixel
Why: A bit is a single 0 or 1, the smallest piece of data a computer can store; everything else is built from bits.

### How many bits make a byte?
- [x] 8
- [ ] 4
- [ ] 16
- [ ] 1000
Why: A byte is a group of 8 bits, which is enough to store one letter or symbol, such as the 'A' in your name.

### Order from smallest: KB, MB, GB means...
- [x] KB < MB < GB
- [ ] GB < MB < KB
- [ ] MB < KB < GB
- [ ] KB = MB = GB, all the same
Why: Each step up is about 1000 times bigger: 1 MB is about 1000 KB, and 1 GB is about 1000 MB.

### Which is the biggest?
- [x] 1 TB
- [ ] 500 GB
- [ ] 1 GB
- [ ] 1 MB
Why: A terabyte is about 1000 gigabytes, so 1 TB is bigger than 500 GB, and far bigger than 1 GB or 1 MB.

### A photo is usually about...
- [x] A few MB
- [ ] A few bits
- [ ] A few TB
- [ ] A few hundred GB
Why: A phone photo holds millions of pixels, each with colour data, so it usually takes a few megabytes even after compression.

### Internet speed is measured in...
- [x] Megabits per second (Mbps)
- [ ] Gigahertz (GHz)
- [ ] Watts (W)
- [ ] Megabytes stored on the disk (MB)
Why: Network links send data one bit after another, so speed is counted in megabits per second, written Mbps with a small b.

### Because 8 bits = 1 byte, a 16 Mbps link downloads about...
- [x] 2 MB per second
- [ ] 16 MB per second
- [ ] 128 MB per second
- [ ] 1 bit per second
Why: There are 8 bits in a byte, so divide megabits by 8: 16 ÷ 8 gives about 2 megabytes each second.

### How many different values can a single byte (8 bits) represent?
- [x] 256 (from 0 to 255)
- [ ] 8 (one for each bit)
- [ ] 100 (from 0 to 99)
- [ ] 16 (from 0 to 15)
Why: Each extra bit doubles the number of patterns, and 2 multiplied by itself 8 times is 256, so values run from 0 to 255.

### If your internet connection downloads at 80 Mbps, the file download speed is roughly...
- [x] 10 MB/s
- [ ] 80 MB/s
- [ ] 800 MB/s
- [ ] 1 MB/s
Why: Divide by 8 because each byte is 8 bits: 80 Mbps ÷ 8 is about 10 megabytes per second.

### In binary, what number does the bit pattern '00000101' represent?
- [x] 5
- [ ] 3
- [ ] 7
- [ ] 10
Why: Reading from the right, the place values are 1, 2, 4, 8 and so on; the 1s sit in the 4 and 1 places, so 4 + 1 = 5.
