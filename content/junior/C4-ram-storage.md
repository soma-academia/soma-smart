# C4 · RAM & Storage

## Read

### 🎒 RAM is the backpack

RAM (Random Access Memory) holds what the computer is using right now: the open app, the page you're reading. It is very fast but it empties when you switch off.

### 📚 Storage is the shelf

Storage (the disk) keeps everything even with the power off: your apps, documents, photos, music. SSDs are fast; older hard disks (HDD) spin a platter and are slower.

### 🚀 SSD vs HDD

An SSD (Solid State Drive) has no moving parts and loads much faster than a spinning hard disk. The fastest type, NVMe, makes programs and files open quickly.

### 🐌 When RAM fills up

If RAM fills, the computer borrows slower space on the disk and everything feels sluggish. Closing unused browser tabs and apps frees the backpack.

### 📏 How big?

RAM is usually a few GB (e.g. 4, 8, 16). Storage is bigger — often hundreds of GB or 1 TB (terabyte). More RAM helps with many apps open; more storage holds more files.

## Mission: Memory detective

- In Task Manager > Performance (or a monitor), note total RAM and how much is in use.
- Open about ten browser tabs and check RAM again. Did it rise?
- Find whether your disk is an SSD or HDD, and its size.

Question: RAM in use before and after tabs, and your disk type and size.

## Quiz

### RAM holds...
- [x] What you're using right now
- [ ] Your files, even after shutdown
- [ ] The instructions that start the PC
- [ ] A copy of the whole internet
Why: RAM is fast working memory for the apps and files open now; it is the backpack that empties when the power goes off.

### Which keeps files when the power is OFF?
- [x] Storage (the SSD or hard disk)
- [ ] RAM (the working memory)
- [ ] CPU cache (on the processor)
- [ ] The graphics card's VRAM
Why: Storage is non-volatile, so it keeps your files with no power; RAM, VRAM and cache are volatile and lose their contents.

### Which is faster?
- [x] An SSD
- [ ] An old spinning hard disk
- [ ] A DVD
- [ ] A floppy disk
Why: An SSD stores data on flash chips with no moving parts, so it never waits for a disk to spin or an arm to move.

### If RAM fills up, the computer...
- [x] Slows down
- [ ] Speeds up
- [ ] Gets more storage space
- [ ] Deletes your open files
Why: With no free RAM, the computer moves data out to the much slower disk and back again, so everything takes longer.

### A good fix when RAM is full is to...
- [x] Close unused tabs and apps
- [ ] Delete old photos from the disk
- [ ] Open more apps to share the load
- [ ] Turn up the screen brightness
Why: Every open tab and app takes up RAM; closing the ones you don't need frees space for the work you are doing.

### RAM sizes are usually around...
- [x] 4, 8 or 16 GB
- [ ] 500 GB to 2 TB
- [ ] 3 to 5 GHz
- [ ] 4, 8 or 16 MB
Why: Laptops and PCs today usually have a few gigabytes of RAM; hundreds of gigabytes is the size of storage, not RAM.

### The fastest common storage type is...
- [x] NVMe SSD
- [ ] SATA hard disk
- [ ] USB flash disk
- [ ] DVD-ROM
Why: NVMe SSDs connect over fast PCIe lanes, so they read and write data many times faster than spinning hard disks.

### An SSD is much faster than an old mechanical HDD because...
- [x] It uses flash memory chips with no moving parts
- [ ] It has a spinning metal disk that turns very fast
- [ ] It keeps all data in RAM while the PC is on
- [ ] It is physically bigger than a hard disk
Why: A hard disk must spin its platter and move a reading arm to find data; flash chips are read electronically with no waiting.

### What happens when your PC runs out of physical RAM while many apps are open?
- [x] It swaps data to disk (virtual memory), so it slows
- [ ] It moves data into the CPU cache, which speeds it up
- [ ] It deletes your saved files to make space
- [ ] It shuts down at once to protect the RAM
Why: The disk stands in for RAM as virtual memory, but even an SSD is far slower than RAM, so the whole PC lags.

### Which type of storage retains data even when unplugged?
- [x] Non-volatile storage, like an SSD or flash disk
- [ ] RAM
- [ ] CPU cache
- [ ] Volatile memory, like the RAM in a laptop
Why: Non-volatile storage keeps data without power, which is why your files are still there the next time you switch on.
