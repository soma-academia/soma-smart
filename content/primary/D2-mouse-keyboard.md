# D2 · Mouse & Keyboard

## Read

### 🖱️ Using the mouse

The mouse moves a pointer on the screen. Left-click to choose. Double-click to open. Right-click shows a menu of extra choices. Drag = hold the button and move.

### ⌨️ The keyboard

Keys type letters and numbers. The long bar is the Spacebar. Enter starts a new line or confirms. Backspace rubs out the letter before the cursor.

### ⇧ Shift and Caps

Hold Shift to type a CAPITAL letter or the symbol on top of a key. Caps Lock keeps all letters capital until you press it again.

### ✂️ Copy, cut, paste

Ctrl + C copies, Ctrl + X cuts (moves), Ctrl + V pastes. Ctrl + Z undoes a mistake. These shortcuts save you a lot of time — they work in school work too.

### 👆 Touch screens

On a phone or tablet, your finger is the mouse. Tap to choose, press-and-hold for a menu, swipe to scroll. Same ideas, different tool.

## Quiz

### To OPEN a file with the mouse you usually...
- [x] Double-click it
- [ ] Right-click once
- [ ] Shake the mouse
- [ ] Press Enter twice
Why: A double-click opens things.

### Right-click is used to...
- [x] Show a menu of extra choices
- [ ] Delete the computer
- [ ] Turn off the screen
- [ ] Type a capital letter
Why: Right-click opens a context menu.

### Which shortcut COPIES?
- [x] Ctrl + C
- [ ] Ctrl + V
- [ ] Ctrl + Z
- [ ] Ctrl + P
Why: C for copy.

### Ctrl + V does what?
- [x] Pastes
- [ ] Copies
- [ ] Deletes everything
- [ ] Prints
Why: V pastes what you copied.

### To type a CAPITAL letter you hold...
- [x] Shift
- [ ] Spacebar
- [ ] Enter
- [ ] Backspace
Why: Shift gives capitals and top symbols.

### Backspace is used to...
- [x] Rub out the letter before the cursor
- [ ] Save the file
- [ ] Open a menu
- [ ] Start a game
Why: It deletes the previous character.

### On a touch screen, press-and-hold usually...
- [x] Opens a menu
- [ ] Turns off the phone
- [ ] Deletes the app
- [ ] Calls someone
Why: Press-and-hold is like a right-click.

### The longest key on the keyboard is the...
- [x] Spacebar
- [ ] Enter key
- [ ] Shift key
- [ ] Escape key
Why: The Spacebar separates words with spaces.

### Which keyboard shortcut UNDOES a mistake?
- [x] Ctrl + Z
- [ ] Ctrl + C
- [ ] Ctrl + V
- [ ] Ctrl + S
Why: Ctrl + Z undoes the last action.

### Holding the mouse button while moving it across the screen is called...
- [x] Dragging
- [ ] Clicking
- [ ] Typing
- [ ] Scrolling
Why: Dragging moves items on screen.
