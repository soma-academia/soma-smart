# S6 · Data Communication

## Read

### 📨 The five parts of communication

Every data communication has five parts: a sender, a receiver, the message (the data), a transmission medium that carries it (cable or radio waves), and a protocol: the agreed rules both sides follow so they understand each other. An M-Pesa message from one phone to another uses all five.

### ↔️ Direction: simplex, half-duplex, full-duplex

Simplex sends one way only, like a radio broadcast. Half-duplex sends both ways but one at a time, like a walkie-talkie ("over!"). Full-duplex sends both ways at once, like a phone call.

### 📜 Protocols and layered models

Protocols are rules for formatting, addressing and checking data. The internet uses the TCP/IP suite: IP (Internet Protocol) addresses and routes packets; TCP (Transmission Control Protocol) makes sure they all arrive in order. The OSI (Open Systems Interconnection) model describes networking in seven layers, from the physical cable up to the application you use.

### 🧵 Guided media: cables

Guided media send signals along a physical path. Twisted-pair copper cable (as in Ethernet) is cheap and common. Coaxial cable is used for TV and some internet connections. Fibre-optic cable carries light, so it is very fast, crosses long distances and is not disturbed by electrical interference. It links Kenya to the world under the sea.

### 📡 Unguided media and bandwidth

Unguided (wireless) media use radio waves, microwaves, infrared or satellite links: Wi-Fi, Bluetooth and mobile data. Bandwidth is how much data a link can carry per second (for example 100 Mbps). A modem modulates digital data into a signal for the medium and demodulates it back at the other end.

## Listen

- Communication needs a sender, a receiver, a message, a medium and a protocol.
- Simplex is one way, half-duplex takes turns, and full-duplex goes both ways at once.
- Protocols are the agreed rules; the internet uses TCP/IP.
- Twisted pair is cheap, coaxial carries TV, and fibre carries light very fast.
- Wireless media include Wi-Fi, Bluetooth, mobile data and satellite.
- Bandwidth is how much data a link carries per second.
- A modem modulates and demodulates signals between devices.

### Task: pick

#### A walkie-talkie lets both people talk, but only one at a time. Which mode is this?
- [ ] Simplex
- [x] Half-duplex
- [ ] Full-duplex
- [ ] No mode
Why: Half-duplex goes both ways but takes turns; a phone call, where both talk at once, is full-duplex.

#### Which part of communication is "the agreed rules both sides follow"?
- [ ] The medium
- [ ] The sender
- [x] The protocol
- [ ] The receiver
Why: Without shared rules (a protocol) the receiver could not make sense of the message.

#### Which cable is NOT disturbed by electrical interference because it carries light?
- [ ] Twisted pair
- [ ] Coaxial
- [x] Fibre-optic
- [ ] Power cable
Why: Fibre sends pulses of light through glass, so nearby electrical noise cannot affect it.

## Quiz

### Which is NOT one of the five parts of data communication?
- [ ] Sender
- [ ] Protocol
- [x] Keyboard
- [ ] Message
Why: The five parts are sender, receiver, message, medium and protocol; a keyboard is just an input device.

### A radio station broadcasting to listeners is an example of...
- [x] Simplex
- [ ] Half-duplex
- [ ] Full-duplex
- [ ] A protocol
Why: Data flows one way only: listeners cannot transmit back on the same channel.

### A normal phone call is...
- [ ] Simplex
- [ ] Half-duplex
- [x] Full-duplex
- [ ] A transmission medium
Why: Both people can speak and hear at the same time, so data flows both ways at once.

### What does TCP do in the TCP/IP suite?
- [ ] Gives every device its address and picks routes
- [x] Makes sure all packets arrive and in order
- [ ] Converts digital data into a radio signal
- [ ] Sets the speed of the link in Mbps
Why: IP handles addressing and routing; TCP checks for lost packets and puts them back in order.

### How many layers does the OSI model have?
- [ ] 3
- [ ] 5
- [x] 7
- [ ] 10
Why: OSI has seven layers, from the physical cable at the bottom up to the application you use at the top.

### Fibre-optic cable carries data as...
- [ ] Electric current
- [x] Pulses of light
- [ ] Sound waves
- [ ] Radio waves
Why: Light through glass gives fibre its very high speed and long reach, free from electrical interference.

### Which is unguided (wireless) media?
- [ ] Twisted-pair cable
- [ ] Coaxial cable
- [x] Wi-Fi
- [ ] Fibre-optic cable
Why: Unguided media send radio waves through the air, so no cable guides the signal as with twisted pair or fibre.

### Bandwidth describes...
- [x] How much data a link can carry per second
- [ ] How far a signal can travel before it fades
- [ ] How many devices can share one Wi-Fi network
- [ ] The physical thickness of the cable in mm
Why: Bandwidth is measured in bits per second, such as 100 Mbps; higher bandwidth means more data flows at once.

### What does a modem do?
- [ ] Joins devices in a LAN and sends data to one
- [x] Converts digital data to a signal and back
- [ ] Stores web pages so they load faster later
- [ ] Sets the rules both devices follow
Why: MOdulator-DEModulator: it turns digital data into a signal for the medium and back again at the other end.

### Why are undersea fibre cables important for Kenya?
- [ ] They supply electricity to the national grid
- [x] They carry Kenya's internet traffic to other countries
- [ ] They carry TV signals only, not internet data
- [ ] They send mobile data by radio to phones along the coast
Why: International internet traffic travels through undersea fibre cables that land at Mombasa.
