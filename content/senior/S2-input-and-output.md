# S2 · Input & Output

## Read

### ⌨️ Input devices

Input devices turn things in the real world into data the computer can process. Keyboards and mice are the familiar ones. Others include touch screens, microphones, cameras and scanners, and sensors that measure temperature, light or movement.

### 🔎 Automatic data capture

Some input devices read data without anyone typing. A barcode or QR code reader at the supermarket, Optical Mark Recognition (OMR) for multiple-choice answer sheets, Magnetic Ink Character Recognition (MICR) for the numbers on bank cheques, and fingerprint readers (biometrics) for identity.

### 🖨️ Output devices

Output devices present processed data to people. A monitor or projector gives soft copy, which you can see but not hold. A printer gives hard copy on paper; inkjets spray tiny ink drops, laser printers fuse toner with heat. Speakers and headphones give sound output.

### 🔁 Both input and output

Some devices do both jobs. A touch screen shows information and accepts taps. A headset has speakers and a microphone. A storage drive receives data and gives it back later.

### 🔌 Connecting devices

Devices connect through ports and wireless links: USB for most accessories, HDMI for screens and projectors, audio jacks, and wireless such as Bluetooth and Wi-Fi. Pick devices by the job: speed, accuracy, cost, the volume of data, and the needs of the user, for example screen readers for blind users.

### Task: pick

#### A school wants to mark 500 multiple-choice answer sheets quickly. Which input method fits best?
- [ ] Typing every answer by keyboard
- [x] Optical Mark Recognition (OMR)
- [ ] A microphone
- [ ] A fingerprint reader
Why: OMR reads the shaded marks on answer sheets automatically, which is fast and accurate for large volumes.

#### A bank needs to read the account numbers printed on cheques. Which technology does this?
- [ ] QR codes
- [ ] A webcam
- [x] Magnetic Ink Character Recognition (MICR)
- [ ] A touch screen
Why: Cheque numbers are printed in magnetic ink, so MICR can read them reliably even through stamps or marks.

## Quiz

### What is the job of an input device?
- [x] To get data into the computer
- [ ] To show results on paper
- [ ] To cool the processor
- [ ] To store files permanently
Why: Input devices turn actions and the real world (keys, sound, light, touch) into data the computer can process.

### Which gives a hard copy?
- [ ] A monitor
- [ ] A projector
- [x] A printer
- [ ] A speaker
Why: Hard copy is output you can hold, like a printed page; screens and projectors give soft copy.

### Which device is both input and output?
- [ ] Keyboard
- [x] Touch screen
- [ ] Printer
- [ ] Scanner
Why: A touch screen displays information (output) and senses your finger (input).

### A supermarket till reads product prices using...
- [x] A barcode reader
- [ ] MICR
- [ ] A plotter
- [ ] A projector
Why: Barcodes encode the product number; the reader scans it and the system looks up the price.

### Which technology reads the shaded answers on multiple-choice exam sheets?
- [ ] MICR
- [x] OMR
- [ ] HDMI
- [ ] Bluetooth
Why: Optical Mark Recognition detects where marks are on a printed form.

### A laser printer forms the image using...
- [ ] Sprayed ink drops
- [ ] Sound waves
- [x] Toner fused with heat
- [ ] Magnetic ink
Why: Laser printers attract powdered toner to the paper and melt it in place; inkjets are the ones that spray ink.

### Which port is most often used to connect a projector or TV screen?
- [ ] Ethernet
- [x] HDMI
- [ ] Audio jack
- [ ] SIM slot
Why: HDMI carries high-quality video and sound to displays.

### A fingerprint reader is an example of...
- [x] Biometric input
- [ ] Soft copy output
- [ ] A storage device
- [ ] A network cable
Why: Biometric devices identify people by body features like fingerprints or faces.

### Which is soft copy output?
- [ ] A printed report
- [x] A document shown on a monitor
- [ ] A photocopy
- [ ] A receipt
Why: Soft copy is displayed on a screen and disappears when you close it; hard copy is printed.

### For a blind learner, which device helps most with output?
- [ ] A bigger monitor
- [ ] A colour printer
- [x] A screen reader with speakers or headphones
- [ ] A webcam
Why: Screen readers turn on-screen text into speech, so choosing devices means thinking about the user's needs.
