# S3 · Storage & the CPU

## Read

### 🧠 Primary storage

Primary storage is memory the CPU (Central Processing Unit) uses directly. RAM (Random Access Memory) holds the programs and data in use right now and is volatile: it is wiped when power goes off. ROM (Read-Only Memory) is non-volatile and holds start-up instructions (firmware). Cache is a small, very fast memory close to the CPU for data it needs again and again.

### 💾 Secondary storage

Secondary storage keeps files when the power is off: hard disk drives (HDD) with spinning platters, solid-state drives (SSD) with no moving parts, USB (Universal Serial Bus) flash drives and memory cards, optical discs such as CDs (Compact Discs) and DVDs (Digital Versatile Discs), and cloud storage on someone else's servers over the internet.

### 📏 Measuring storage

1 byte is 8 bits. Storage sizes go kilobyte (KB), megabyte (MB), gigabyte (GB), terabyte (TB). In computing, each step is traditionally 1024 times the last (1 KB = 1024 bytes), though drive makers often use 1000. A photo might be 3 MB; a phone might store 128 GB.

### 🛡️ Caring for storage

Back up important files in at least two places. Eject flash drives before pulling them out. Keep hard disks away from knocks, heat and strong magnets. Scan removable drives for malware, because they spread infections between computers.

### ⚙️ Inside the CPU

The CPU has a Control Unit that directs the fetch–decode–execute cycle, an Arithmetic Logic Unit (ALU) that does calculations and comparisons, and registers: tiny, ultra-fast storage inside the CPU. Speed depends on clock speed (in GHz), the number of cores working in parallel, and cache size.

## Listen

- Primary storage is used directly by the CPU: RAM, ROM and cache.
- RAM is volatile and forgets everything when the power goes off.
- ROM keeps its start-up instructions even without power.
- Secondary storage, like SSDs, hard disks and flash drives, keeps files long-term.
- One byte is eight bits; then kilobytes, megabytes, gigabytes and terabytes.
- Back up important files, and always eject flash drives safely.
- Inside the CPU, the control unit directs, the ALU calculates, and registers hold data.

## Quiz

### Which memory loses its contents when the power goes off?
- [x] RAM
- [ ] ROM
- [ ] SSD
- [ ] DVD
Why: RAM is volatile; ROM and secondary storage are non-volatile and keep their data.

### What does ROM usually store?
- [ ] Photos and documents you save each day
- [x] Start-up instructions (firmware)
- [ ] Web pages you visit
- [ ] Temporary calculations only
Why: ROM holds instructions the computer needs to start, and keeps them without power.

### Which part of the CPU performs calculations and comparisons?
- [ ] Control unit
- [x] Arithmetic Logic Unit (ALU)
- [ ] Power supply
- [ ] Main memory (RAM) that holds running programs
Why: The ALU does arithmetic (add, subtract) and logic (compare, AND, OR).

### What is the job of the control unit?
- [x] To direct the fetch–decode–execute cycle
- [ ] To store programs and data permanently, even with power off
- [ ] To display images
- [ ] To connect to Wi-Fi
Why: The control unit coordinates the CPU, deciding what happens next at each step.

### Why is an SSD faster than a hard disk drive?
- [ ] It is always larger
- [x] It has no moving parts
- [ ] It uses magnetic ink
- [ ] It spins its disk much faster than a hard disk does
Why: A hard disk must spin and move a read head; an SSD reads its flash chips electronically.

### Cache memory is used to...
- [ ] Keep files safe after the computer is switched off
- [x] Hold data the CPU will need again soon
- [ ] Print documents faster
- [ ] Replace the hard disk
Why: Cache is small, very fast memory beside the CPU; keeping frequently used data there cuts the time the CPU waits for slower RAM.

### How many bits are in one byte?
- [ ] 4
- [x] 8
- [ ] 10
- [ ] 1024
Why: A byte is 8 bits, enough for 256 different values.

### Which is the best way to protect important files?
- [ ] Keep one copy on a flash drive only
- [x] Keep backups in at least two different places
- [ ] Store them only in RAM, where the CPU can reach them fastest
- [ ] Never save them
Why: Any single device can fail, get lost or get infected; separate backups protect you.

### What does the clock speed of a CPU (in GHz) measure?
- [ ] How much data it can store in its own memory
- [x] How many cycles it can run per second
- [ ] Its temperature
- [ ] Its screen size
Why: 3 GHz means about 3 billion clock cycles per second; more cycles generally means faster work.

### Which is an example of cloud storage?
- [ ] A DVD in a drawer
- [ ] A flash drive plugged into a laptop's USB port
- [x] Files kept on an online service's servers
- [ ] A printed photo
Why: Cloud storage keeps your files on another company's servers, reached over the internet.
